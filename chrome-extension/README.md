# 電商賣場出貨與真實利潤助手 (Chrome 擴充功能 Manifest V3)

專為電商賣家量身打造的 Chrome 瀏覽器擴充功能。當您在瀏覽 **蝦皮賣家中心 (Shopee)**、**MO店+ (Momo)** 或 **酷澎商城 (Coupang Wing)** 的「訂單詳情頁面」時，右側將自動滑出浮動面板，即時呈現真實淨利與庫存/在途採購預警，並提供一鍵連動 Google Apps Script (GAS) 執行出貨、扣庫存與刪單。

---

## 🌟 核心特色

1. **純淨財務結算（嚴格規範）**：
   - 介面**不顯示「訂單總售價」**。
   - 💵 **實際入帳金額**（由網頁抓取）
   - 📉 **平台手續費**（由網頁抓取，無則為 $0）
   - 📦 **總進價成本**（由試算表 products 之 `cost_price` × 訂單數量加總）
   - ⭐ **真實淨利** = 實際入帳金額 - 平台手續費 - 總進價成本
   - 📈 **實賺淨利率** = (真實淨利 ÷ 實際入帳金額) × 100%
2. **Shadow DOM 樣式隔離**：
   - 所有介面與樣式 100% 封裝於 Shadow DOM 內部，完全不破壞賣場後台排版，亦不受賣場 CSS 干擾。
3. **庫存與在途採購雙重燈號**：
   - 🟢 **現貨充足**（現有庫存 ≥ 訂單需求量）
   - 🟡 **現貨不足，但有在途採購**（現有庫存不夠，但採購單 purchase_orders 已在途訂購中）
   - 🔴 **缺貨預警**（現有庫存不足且無在途採購）
4. **出貨黃金三部曲（與管理 APP 100% 一致）**：
   - 點擊【🚀 執行出貨】時：
     1. 自動按效期早晚（FIFO 先進先出）計算批次庫存。
     2. 呼叫 GAS `stockOut` 扣除真實庫存，並自動寫入 `transactions` 交易流水帳。
     3. 呼叫 GAS `deleteOnlineOrder` 自動自試算表「網路訂單」工作表刪除該筆訂單。
     4. 按鈕轉換為綠色「✅ 出貨成功，庫存已扣除」，杜絕重複扣庫存。
5. **視覺化元素選取器 (Visual Element Picker)**：
   - 點擊【🎯 選取】，在賣場網頁上點一下入帳金額或手續費元素，即可自動鎖定並依平台獨立記憶。
6. **透明度控制與抽屜收合**：
   - 支援 20% ~ 100% 透明度滑桿，滑鼠移開呈現半透明不遮擋頁面、滑鼠懸停 100% 清晰。
7. **100% 安全隱私防護**：
   - 所有資料與 GAS 網址僅儲存於您本機的 `chrome.storage.local`，絕無任何外部伺服器或轉發站。

## 🛠️ 安裝教學（1 分鐘快速載入）

1. 打開 Google Chrome 瀏覽器，在網址列輸入：
   ```
   chrome://extensions/
   ```
2. 開啟右上角的**「開發人員模式」**（Developer mode）開關。
3. 點選左上角的**「載入未封裝項目」**（Load unpacked）。
4. 在檔案選擇器中，選取本專案的 `chrome-extension` 資料夾。
5. 安裝完成！瀏覽器右上角的拼圖擴充功能清單中即可看到「電商賣場出貨與真實利潤助手」。

---

## ⚙️ 首次設定指南

1. **設定 Google Apps Script Web App URL**：
   - 點擊瀏覽器工具列上的擴充功能圖示，或在賣場浮動面板中點擊右上角的【⚙️】設定。
   - 在「Google Apps Script Web App URL」欄位中貼入您現有庫存管理系統的 GAS 部署網址（例如：`https://script.google.com/macros/s/.../exec`）。
   - 點擊【💾 儲存並同步】（或【🧪 測試連線】確認顯示連線成功）。
2. **設定賣場金額選取器**：
   - 進入任一電商賣場的「訂單詳情頁面」（如蝦皮訂單詳情）。
   - 點擊面板右上角的【⚙️】設定。
   - 在「💵 實際入帳金額」旁點擊【🎯 選取】，此時滑鼠移到賣場網頁上的「買家實付/撥款金額/入帳金額」數字上方點一下，系統即會自動抓取並儲存 Selector。
   - 手續費亦可使用相同方式選取。

## 📂 檔案架構

```
chrome-extension/
├── manifest.json       # 擴充功能設定檔 (Manifest V3, 權限與網域匹配)
├── background.js       # Background Service Worker (處理 GAS API 請求與 CORS)
├── content.js          # Content Script (Shadow DOM、浮動抽屜、視覺選取器、出貨邏輯)
├── styles.css          # Shadow DOM 專屬現代化深色 UI 樣式
├── popup.html          # 工具列捷徑設定彈窗 HTML
├── popup.js            # 工具列彈窗狀態與連線邏輯
├── icons/              # 擴充功能各尺寸圖示 (icon16, icon48, icon128)
└── README.md           # 本使用說明文件
```
