# 採購單儲位一鍵批改、規格數量全介面展示與獨立重新整理計畫

本計畫針對進銷存系統的三項核心操作體驗進行升級：在採購單核對入庫提供「頂部儲位一鍵批改」極速作業；在全系統各 UI 介面清晰展示「所有規格個別庫存數量（無庫存以灰色標示）」；並為各大功能主介面建立「模組專屬重新整理按鈕」，僅拉取該頁面所屬試算表，避免全域同步耗時。

- **Apps Script 異動規範提醒（重要規範）**：
  - ✅ **本次更新完全不需修改或重新部署 Google Apps Script 腳本**！
  - 現行 Apps Script (v2.4) 後端本即支援單一工作表之 GET 讀取端點（`getProducts`, `getStock`, `getPurchaseOrders`, `getOnlineOrders`, `getTransactions`），前端將直接調用專屬端點，您**完全不需要前往 Google 試算表重新貼代碼或發布**。
- **確認決策 1（採購單入庫儲位一鍵批改）**：
  - 於「進貨入庫前確認預覽面板」頂部增設**儲位批改工具列**（倉庫、樓層、區域），點擊「一鍵套用至全部品項」後，自動將當前核對清單中所有商品之入庫儲位一次性填入，並支援個別微調。
- **確認決策 2（全 UI 介面商品規格個別數量展示）**：
  - 統一於所有品項展示介面（庫存總覽、商品管理、採購單選擇、出貨確認、商品掃描）顯示商品所有規格與其個別庫存數量。
  - **有庫存規格**以鮮明對比之數字標示；**無庫存規格**（數量為 0）以半透明冷灰色標示，一眼即可看出哪些規格缺貨。
- **確認決策 3（各大主功能專屬獨立重新整理）**：
  - 各大主功能頁面（庫存總覽、商品資料庫、採購管理、網路訂單、交易歷史）頂部新增「重新整理」按鈕。
  - 點擊時**僅從 Google 試算表拉取該頁面所屬的工作表資料**（單次請求僅約 0.3~0.6 秒），不會發起全 APP 6 個工作表的重載，更不觸發佇列寫入，大幅提升日常檢視速度。

## 1. 概述與核心概念 (Overview & Core Concept)

* **目標情境**：
  1. 倉庫人員在進貨核對時，經常一次到貨數十種商品但皆置於同一個貨架（如：1F 倉庫 A區），過去需逐一選取儲位，操作繁瑣。
  2. 門市與管理人員查詢商品時，需要直接看見各規格（如 S/M/L、黑/白/紅）各自還有多少現貨，而不是只看單一總數。
  3. 各模組操作人員只想即時刷新當前頁面資料（例如剛在試算表編輯了採購單），無需忍受全站同步的漫長等待。
* **主要價值**：
  - 核對入庫流程操作步驟減少 80%。
  - 全流程規格庫存即時透通，徹底避免超賣與誤判。
  - 頁面更新速度自 3~5 秒縮減至 0.5 秒以內。

## 2. 使用者體驗與視覺設計 (User Experience & Visual Design)

### 關鍵操作流程與介面規劃 (Key User Flows)

#### A. 採購單核對入庫：儲位一鍵批改工具列
1. 進入採購單核對入庫或發票辨識後，開啟「進貨入庫前確認預覽面板」。
2. 清單頂部顯示**「一鍵批改入庫儲位」**工具列：
   - 預設載入常用倉庫、樓層、區域下拉選單。
   - 點擊 **「一鍵套用至全部品項」** 按鈕，清單中所有商品立即批次改為指定儲位。
   - 仍可針對少數特殊品項直接在該列做個別修正。

```
┌────────────────────────────────────────────────────────────────────────┐
│ 進貨入庫前確認預覽面板                                                  │
├────────────────────────────────────────────────────────────────────────┤
│ 📍 一鍵批改儲位: [ 倉庫 ▼ ] [ 1F ▼ ] [ A區 ▼ ]   [ ⚡ 一鍵套用至全部品項 ] │
├────────────────────────────────────────────────────────────────────────┤
│ 品名 / 系統對應商品   │ 規格   │ 數量 │ 單價 │ 入庫儲位         │ 小計 │
│ ─────────────────────┼────────┼──────┼──────┼──────────────────┼──────│
│ 經典款電話機 (K01)   │ 白色   │  10  │ 500  │ 倉庫 / 1F / A區  │ 5000 │
│ 經典款電話機 (K01)   │ 黑色   │   5  │ 500  │ 倉庫 / 1F / A區  │ 2500 │
└────────────────────────────────────────────────────────────────────────┘
```

#### B. 全 UI 介面商品規格個別數量展示規範
1. 建立通用元件 `<ProductSpecStockBadges />`，解析商品全部已設定規格以及目前庫存中的現有規格。
2. 視覺排版：
   - 每個規格顯示名稱與數量，數字使用等寬數字（`font-mono tabular-nums`）。
   - **庫存 > 0**：`text-slate-200 bg-white/5 border border-white/10`，數字呈現明亮天空藍/翡翠綠。
   - **庫存 = 0**：`text-slate-500 bg-white/[0.02] border border-white/5 line-through-none`，明確標註 `缺貨 (0)` 或 `0`，視覺降噪。
3. 涵蓋頁面：
   - **庫存管理 (Home)**：商品列表卡片與表格直接展示規格庫存分佈。
   - **商品資料庫 (Products)**：品項詳情與卡片清楚呈現各規格即時庫存。
   - **採購單 (Purchases)**：新增品項選擇與核對時顯示各規格現有量，輔助採購決策。
   - **出貨與出庫 (StockManage / OutboundCart)**：選取規格按鈕即時帶出該規格剩餘庫存。
   - **條碼掃描 (Scan)**：掃描後直接展示各規格即時分佈。

#### C. 各大功能專屬獨立重新整理按鈕
1. 各主功能頁面頂部工具列（搜尋列旁）配置統一的模組專用重新整理控制項：
   - **庫存總覽頁**：`[ 🔄 重新整理庫存 ]`（調用 `refreshStock()`）
   - **商品管理頁**：`[ 🔄 重新整理商品 ]`（調用 `refreshProducts()`）
   - **採購進貨頁**：`[ 🔄 重新整理採購單 ]`（調用 `refreshPurchaseOrders()`）
   - **網路訂單頁**：`[ 🔄 重新整理訂單 ]`（調用 `refreshOnlineOrders()`）
   - **交易紀錄頁**：`[ 🔄 重新整理交易 ]`（調用 `refreshTransactions()`）
2. 點擊時按鈕旋轉，提示「正在重新載入...」，完成後顯示輕量綠色 Toast 提示更新筆數，耗時僅約 0.5 秒。

## 3. 關鍵產品決策與權衡 (Product Decisions & Trade-Offs)

- **決策 1：儲位批改是否需要勾選方塊（Checkboxes）？**
  - *選擇方案*：採用「頂部設定儲位並一鍵套用至所有品項」，不強制增加每列勾選框。
  - *原因*：使用者在核對入庫時，整批貨通常是同一托盤或同貨架進入；直接一鍵套用全部、若有個別特殊品項再單獨改那一行，操作速度最快。
- **決策 2：單頁重新整理是否包含未同步佇列？**
  - *選擇方案*：模組專用重新整理僅拉取雲端資料更新本機讀取快取，**絕不干擾或重送未發送的本機離線同步佇列（SyncQueue）**。
  - *原因*：避免使用者在只想快速刷新畫面時，意外觸發卡單或重複發送寫入請求。
- **決策 3：Google Apps Script 腳本相容性**
  - *選擇方案*：純前端重構查詢分流，保持後端 Apps Script 完全不變。
  - *原因*：使用者無須再進行繁複的 Google 試算表權限驗證與代碼覆蓋部署。

### 具體實作規劃：
1. **`src/store/useStore.ts`**：
   - 封裝單項資料重新整理方法：
     - `refreshStock()`
     - `refreshProducts()`
     - `refreshPurchaseOrders()`
     - `refreshOnlineOrders()`
     - `refreshTransactions()`
   - 每項方法獨立處理該工作表之資料正規化、去重、快取儲存（IndexedDB）與 Toast 回饋。
2. **`src/components/ProductSpecStockBadges.tsx`**：
   - 封裝通用規格數量拆解元件，接收 `product` 與 `stock` 清單。
   - 提取商品已宣告的所有規格（以逗號、斜線或頓號分割）與實際已有庫存之規格。
   - 計算各規格在各儲位合計之目前數量，標示正常數量與 `0 (缺貨)` 灰字。
3. **`src/pages/Purchases.tsx`**：
   - 在 `showConfirmPanel` 核對入庫對話框中加入頂部儲位批改工具列（`batchLocation`, `batchFloor`, `batchArea` + 一鍵批改按鈕）。
   - 在採購單列表頁頂部新增「重新整理採購單」按鈕。
   - 採購單各檢視區塊套用規格數量展示。
4. **`src/pages/Home.tsx`**、**`src/pages/Products.tsx`**、**`src/pages/Orders.tsx`**、**`src/pages/History.tsx`**：
   - 於頂部工具列整合專屬重新整理按鈕。
   - 於商品清單與卡片中整合規格個別數量標籤。
